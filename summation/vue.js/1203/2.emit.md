# Vue.js `emit` 데이터 흐름 정리



## 1. 전체 흐름 요약

| 구분     | 자식 컴포넌트 (`ParentChild`) | 부모 컴포넌트 (`Parent`) |
| :------- | :---------------------------- | :----------------------- |
| **역할** | 신호 발신 (Sender)            | 신호 수신 (Receiver)     |
| **방향** | **Bottom → Up** (상향식)      | 자식 → 부모              |
| **문법** | `emit('이벤트명', 데이터)`    | `@이벤트-명="함수"`      |

---

## 2. 자식 컴포넌트: 이벤트 발신 (Emit)
**파일명:** `ParentChild.vue`

자식은 `defineEmits`로 이벤트를 정의하고, 버튼 클릭 등 특정 시점에 `emit()`을 호출하여 신호를 보냅니다.

### A. 이벤트 정의 (Declaration)
`<script setup>` 내부에서 사용할 이벤트 이름을 배열로 정의합니다.

```javascript
const emit = defineEmits([
  'someEvent', // 1. 사용할 이벤트 이름 정의
  'emitArgs'
])
```

### B. 이벤트 실행 (Trigger)
1. **기본 발신 (인자 없음)** `someEvent`라는 신호만 보냅니다.

```JavaScript

const buttonClick = () => {
  emit('someEvent') 
}

```

2. **데이터 포함 발신 (인자 있음)** `emitArgs`라는 신호와 함께 숫자 `1, 2, 3`을 보냅니다.

```JavaScript

const emitArgs = () => {
  // 첫 번째 인자는 이벤트명, 두 번째부터는 전달할 데이터
  emit('emitArgs', 1, 2, 3) 
}
```

## 3. 부모 컴포넌트: 이벤트 수신 (Listen)
- **파일명**: `Parent.vue`

- 부모는 자식 컴포넌트 태그에서 `@` (v-on) 디렉티브를 사용하여 이벤트를 감지하고 핸들러 함수를 실행합니다.

#### A. 템플릿 연결 (Template)

```html

<ParentChild 
  @some-event="someCallback" 
  @emit-args="getNumbers" 
/>

```

#### B. 핸들러 함수 처리 (Script)

1. **기본 수신** 이벤트가 발생했다는 사실만 확인합니다.

```JavaScript

const someCallback = () => {
  console.log('ParentChild가 발신한 이벤트를 수신했어요')
}
```

2. **데이터 수신 (Parameter)** 자식이 보낸 **인자(1, 2, 3)** 를 매개변수로 받아 처리합니다. (Rest Parameter 활용 예시)

```JavaScript

const getNumbers = (...args) => {
  // args는 [1, 2, 3] 배열로 들어옵니다.
  console.log(args)
  console.log(`ParentChild가 전달한 추가인자 ${args}를 수신했어요`)
}
```
## 4. 핵심 포인트 (Key Takeaways)
1. **단방향 데이터 흐름 보완** : `props`는 부모에서 자식으로 흐르지만, `emit`을 사용하면 자식에서 부모로 소통할 수 있습니다.

2. **데이터 전달** : `emit`의 두 번째 인자부터는 부모 함수의 매개변수로 전달됩니다.

3. **네이밍 컨벤션** (Naming Convention):

    - **발신(Script)** : `camelCase` (예: `someEvent`)
  
    - **수신(Template)** :` kebab-case` (예: `@some-event`)
     
    - Vue가 내부적으로 매핑해주므로 이 관례를 따르는 것이 코드 일관성에 좋습니다.
